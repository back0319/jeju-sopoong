# 연구 데이터 사용

관리자 연구 데이터 메뉴는 오늘 하루, 최근 일주일(오늘 포함 7일), 최근 한달(오늘 포함 30일), 직접 입력한 기간을 지원합니다. 기준은 서버의 한국 영업일입니다. 설문 참여 여부와 포함 재료를 함께 필터링할 수 있고, 화면은 25건씩 표시하며 내보내기는 조회 조건 전체를 포함합니다.

## 파일 구성

- 주문·설문 CSV: 주문당 한 행. 복수 응답은 선택지별 0/1 열이며 단일 응답은 선택지 코드입니다. `items_json`에 모든 구성도 함께 보관합니다.
- 구성별 CSV: 주문 항목당 한 행. 포함·제외·추가 재료의 ID와 당시 이름·가격을 보관합니다.
- 전체 JSON: `metadata`, `orders`, `items`. 메타데이터에 스키마 버전, 생성 시각, 조회기간, 시간대, 화폐, 문항 버전을 포함합니다.
- 문항 코드표: 문항 버전, 문항 ID·본문·유형·필수 여부, 선택지 코드·라벨·연결 재료를 제공합니다.

`record_id`는 주문과 구성을 결합하는 키이며 고객 식별번호가 아닙니다. `item_index`는 주문 안에서의 항목 순서입니다. 모든 CSV는 첫 행이 헤더이고 모든 행의 열 수가 같아 pandas/R/Excel에서 바로 읽을 수 있습니다. 생성 시각과 조회기간도 열로 포함합니다.

## 해석

- 설문에 응답한 문항의 복수 선택지는 선택 1, 비선택 0입니다.
- 설문 미참여·선택 문항 미응답·다른 설문 버전은 빈 값입니다. 빈 값을 0으로 바꾸면 미참여와 비선택이 섞이므로 구분합니다.
- 설문 미참여 주문에는 응답이나 동의 정보를 저장하지 않습니다.
- `internal_test=true`인 자료는 내부 테스트 자료입니다. 확정 동의문 적용 전 자료를 실제 고객 연구 응답과 혼합하지 않도록 구분할 수 있습니다.
- 주문 처리 상태, 관리자 정보, 제출 방지 키는 연구 파일에서 제외합니다. 취소 주문을 포함한 모든 생성 기록이 현재 조회 조건에 포함됩니다.
- 문항 라벨 변경도 새 버전으로 보존합니다. 이전 응답은 이전 버전의 코드표로 해석합니다.

예시:

```python
import pandas as pd
orders = pd.read_csv("juseyo-csv-시작일-종료일.csv")
items = pd.read_csv("juseyo-items-시작일-종료일.csv")
combined = items.merge(orders, on="record_id", suffixes=("_item", "_order"))
```
