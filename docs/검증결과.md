## 운영 화면 자동 갱신 및 한국어 추가 재료

- 관리자 세션을 실시간 구독 전에 연결하고, 토큰 갱신·재연결·온라인 복구·탭 복귀를 처리합니다. 정상 연결은 실시간 이벤트와 10초 보완 조회, 연결 실패는 2초 조회를 사용합니다.
- 운영 화면을 유지한 Playwright 검증에서 실제 WebSocket 이벤트와 새 주문 반영(약 1.2초), 기존 주문 선택 유지를 확인했습니다. WebSocket을 차단하고 최초 로딩 이후 주문을 생성해 자동 조회 반영(약 1.9초)도 확인했습니다. 시간은 테스트 측정값이며 네트워크에 따라 달라집니다.
- 이전 조회 응답이 더 최신 조회 결과를 덮어쓰지 않도록 보호합니다.
- 신규 주문은 추가 재료의 한국어 이름을 스냅샷에 저장합니다. 기존 영문 스냅샷은 원본을 보존하고 운영 상세·연구 데이터 화면에서 한국어로 표시합니다.
